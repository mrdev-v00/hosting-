13.1 — Functions

13.1.1 Intervals

An interval describes allowed real numbers. Square brackets include endpoints; round brackets exclude them.

NotationMeaning
[2,5]2 ≤ x ≤ 5
(2,5)2 < x < 5
[2,5)2 ≤ x < 5
(−∞,4]x ≤ 4
Example: x ≥ −3 and x < 5 becomes [−3,5).

What is a function?

A function assigns exactly one output to every allowed input. Think of it as a machine: input x enters, and f(x) comes out.

Example: f(x)=2x+3. Then f(4)=11.
Not a function: {(1,4),(1,7)} because input 1 has two different outputs.

Domain, codomain and range

Domain = allowed inputs. Codomain = declared target set. Range = outputs actually produced.

Domain traps: denominator ≠ 0; even-root radicand ≥ 0; logarithm argument > 0.
1. f(x)=1/(x−3): domain x≠3.
2. g(x)=√(x+5): domain x≥−5.
3. h(x)=ln(x−2): domain x>2.

One-one and onto

One-one: different inputs never share an output. Onto: every element of the codomain is hit.

Example: f(x)=2x+1 from R to R is one-one and onto. If f(a)=f(b), then a=b. For any y, choose x=(y−1)/2.

Algebraic and transcendental functions

Algebraic functions use algebraic operations and roots: polynomials and rational functions are common examples. Transcendental functions include exponential, logarithmic and trigonometric functions.

Important function families

  • Polynomial: x³−2x+1
  • Rational: (x+1)/(x−2)
  • Exponential: 2ˣ
  • Logarithmic: log₂x
  • Trigonometric: sin x, cos x, tan x
  • Modulus: |x|
  • Quadratic: ax²+bx+c
  • Square-root: √x

Explicit, implicit and parametric

Explicit: y directly in terms of x, e.g. y=x²+1.

Implicit: x and y occur together, e.g. x²+y²=25.

Parametric: x and y are both given using t, e.g. x=t², y=2t.

Even and odd

Even: f(−x)=f(x), giving y-axis symmetry. Odd: f(−x)=−f(x), giving origin symmetry.

Example: x² is even; x³ is odd; x³+x is odd.

Piecewise functions

Example: f(x) = x+2 for x<1 and 3x for x≥1. At x=0 use the first rule; at x=1 use the second.
Practice 20–40:
1. Domain of 1/(x+4). 2. Domain of √(7−x). 3. Is x⁴ even, odd or neither? 4. Is x³−5x even, odd or neither? 5. Domain/range of |x|. 6. Explain why 2x−7 from R to R is one-one and onto.

13.2 — Inverse Functions

An inverse reverses a function. If f takes x to y, f⁻¹ takes y back to x. A function must be one-one on the chosen domain to have an inverse function.

Method

  1. Write y=f(x).
  2. Swap x and y.
  3. Solve for y.
  4. Rename y as f⁻¹(x).
Example: f(x)=3x−5.
y=3x−5 → x=3y−5 → y=(x+5)/3.
So f⁻¹(x)=(x+5)/3.
Verification: f(f⁻¹(x))=x and f⁻¹(f(x))=x.

Quadratic warning

x² is not one-one on all R because f(2)=f(−2). Restricting the domain to x≥0 makes its inverse √x.

The graph of f⁻¹ is the reflection of f in y=x.

Practice 40–50: Find and verify the inverse of f(x)=5x+2. Then find the inverse of x² after restricting the domain to x≥0.

13.4 — Limits

13.4.1 What does x→a mean?

x→a means x gets arbitrarily close to a. A limit asks what output is approached; it does not automatically ask for the function's actual value at a.

Example: lim(x→2)(x+3)=5.

One-sided limits

x→a⁻ approaches from the left; x→a⁺ approaches from the right. A two-sided limit exists when both agree.

Sequences

A sequence is a₁,a₂,a₃,... . Its limit describes what happens as n→∞.

aₙ=1/n → 0 as n→∞.

Limit laws

  • lim(f+g)=lim f+lim g
  • lim(f−g)=lim f−lim g
  • lim(cf)=c lim f
  • lim(fg)=(lim f)(lim g)
  • lim(f/g)=(lim f)/(lim g), if denominator limit ≠0
Example: lim(x→2)(x²+3x−1)=4+6−1=9.

0/0: factor and cancel

lim(x→3)(x²−9)/(x−3). Factor x²−9=(x−3)(x+3), cancel, then substitute 3: answer 6.

Difference of powers

xⁿ−aⁿ=(x−a)(xⁿ⁻¹+xⁿ⁻²a+...+aⁿ⁻¹).

lim(x→2)(x³−8)/(x−2)=lim(x→2)(x²+2x+4)=12.

Rationalization

lim(x→4)(√x−2)/(x−4). Multiply by (√x+2)/(√x+2). Simplify to 1/(√x+2), then substitute 4: 1/4.

Standard limits to master

lim x→0 sin x/x = 1
lim x→0 (1−cos x)/x = 0
lim x→0 (eˣ−1)/x = 1
lim x→0 ln(1+x)/x = 1
lim x→0 ((1+x)ⁿ−1)/x = n
lim x→∞ (1+1/x)ˣ = e
Example: lim(x→0) sin(7x)/x = 7·lim(x→0) sin(7x)/(7x)=7.
Example: lim(x→0)(2ˣ−1)/x = ln 2.
Practice 60–75:
1. lim(x→2)(3x²−x+1). 2. lim(x→5)(x²−25)/(x−5). 3. lim(x→1)(x³−1)/(x−1). 4. lim(x→9)(√x−3)/(x−9). 5. lim(x→0) sin(5x)/(5x). 6. lim(x→0) sin(7x)/x. 7. lim(x→0)(eˣ−1)/x. 8. lim(x→0)((1+x)^5−1)/x. 9. lim(n→∞)1/n. 10. Explain when a two-sided limit fails.

13.5 — Continuity

f is continuous at x=a when:

  1. f(a) exists.
  2. lim(x→a)f(x) exists.
  3. lim(x→a)f(x)=f(a).
Example: Every polynomial is continuous for every real x.
Example: 1/(x−2) is not continuous at x=2 because it is undefined there.

Discontinuities

Removable: a hole can be filled. Jump: left and right limits differ. Infinite: values become unbounded near a vertical asymptote.

For f(x)=2x+1 when x<2 and 3x−1 when x≥2: left limit=5, right limit=5, f(2)=5, so it is continuous at 2.
Practice 75–80: Test continuity at x=3 for f(x)=2x+1 when x<3 and x+4 when x≥3. Show all three conditions.

14.1 — Differentiation

Average rate of change

From x=a to x=b:

[f(b)−f(a)]/(b−a)

This is the secant-line slope.

f(x)=x² from 2 to 5: (25−4)/(5−2)=7.

Instantaneous rate and first principles

f′(x)=lim(h→0)[f(x+h)−f(x)]/h
Derive f=x²:
f′=lim(h→0)[(x+h)²−x²]/h
=lim(h→0)(2x+h)=2x.

14.2 — Applications of Differentiation

Tangent

At x=a, tangent slope is f′(a):

y−f(a)=f′(a)(x−a)
For y=x² at x=2: f(2)=4, f′(2)=4, so y−4=4(x−2), hence y=4x−4.

Normal

If tangent slope is m≠0, normal slope is −1/m.

Increasing/decreasing

f′>0 means increasing; f′<0 means decreasing on the interval being considered.

Stationary points

Stationary points satisfy f′(x)=0. Use derivative sign changes or the second derivative test to classify them.

f=x²−4x+1 → f′=2x−4=0 gives x=2. f″=2>0, so it is a minimum; f(2)=−3. Minimum point=(2,−3).

Optimization workflow

  1. Define the quantity.
  2. Write it as a function.
  3. Differentiate.
  4. Set derivative to zero for candidates.
  5. Classify/check candidates.
  6. Interpret in context.
Practice 90–100: 1. Find tangent and normal to y=x³ at x=1. 2. Determine increasing/decreasing intervals for x³−3x²−9x. 3. Find/classify stationary points of x³−6x²+9x+2. 4. Rectangle perimeter 40: maximize area. 5. s(t)=t³−6t²+9t: find velocity, acceleration and stationary times.
